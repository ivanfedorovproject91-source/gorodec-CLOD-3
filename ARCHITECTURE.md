# Архитектура

- `src/engine/` — рендер на PixiJS. Не знает про React и Telegram. `Camera` — единственное место преобразований мир↔экран (мир: Y вверх, земля y=0; 1 ед. = 10 см).
- `src/engine/Scene.ts` — объекты, выделение, история undo/redo (снимки JSON, до 100 шагов, только в сессии).
- `src/engine/Engine.ts` — рендер + ввод: инструменты select/draw/hand, перетаскивание, ресайз за 8 ручек, отсечение невидимых объектов по границам экрана.
- `src/components/Inspector.tsx` — числовое редактирование выбранного объекта.
- `src/App.tsx` — интерфейс React (панели, тулбары), общается с движком через методы `Engine` и колбэки.
- `src/services/storage.ts` — IndexedDB (один проект `current`).
- `src/types/project.ts` — формат проекта (`formatVersion: 1`), валидация при загрузке/импорте. Подходит для будущей облачной синхронизации.
- `src/platform/telegram.ts` — изолированная интеграция Telegram Mini App.

## Планы по миру (Фазы 2+)
Объекты хранятся в мировых координатах, пространственный индекс — чанки по X (например 2048 ед.), рендер только видимых чанков (culling). Фаза 1 содержит камеру и сетку, чанков пока нет.

## Процедурные здания (Фаза 3)
- `types/building.ts` — параметры (`BuildingParams`), пресеты, допустимые значения, `sanitizeBuilding` (проверка при загрузке/импорте/инспекторе).
- `engine/buildingModel.ts` — `fitHeight` (высота = целое число этажей + крыша) и `applyBuildingPatch`.
- `engine/BuildingRenderer.ts` — отрисовка: корпус, боковая грань (глубина), крыша (плоская/двускатная/односкатная/ступенчатая), фасад (оконный/ленточный/витражный/промышленный), дверь, балконы. Число модулей = round((ширина − поля) / целевой шаг), реальная ширина модуля подгоняется под здание; число этажей берётся из высоты. Мелкие детали отключаются при малом экранном размере (LOD). Текстуры не используются.
- Инвариант: `h = floors * floorHeight + roofHeight(roof)`; roofHeight: плоская 0,8 м, двускатная 4 м, односкатная 3 м, ступенчатая 6 м.
- `Scene` — пространственный индекс: чанки по X (2048 ед.), `visible(minX,maxX)` возвращает объекты в порядке отрисовки; используется для отсечения при рендере и для выбора кликом. Индекс перестраивается лениво после изменений.

## Инфраструктура (Фаза 4)
- Путь — объект `kind: 'path'` с `PathParams` (`types/path.ts`): ломаная в плоскости вида сбоку (x — вдоль, y — высота верхнего края полотна), тип (дорога/шоссе/рельсы/пешеходная), режим (по земле/эстакада/мост/тоннель), полосы, ширина полосы, толщина, сглаживание (Catmull–Rom), опоры. Габариты `x,y,w,h` вычисляются из точек (`updatePathBounds`) и нужны индексу и отсечению.
- Ширина дороги показана как «глубина»: верхняя грань полотна смещается вверх-вправо так же, как боковые грани зданий (`engine/projection.ts`). На ней рисуются разметка, пути и шпалы.
- `engine/pathModel.ts` — геометрия: выборка точек (кэш), обход по длине дуги, попадание в полотно, привязка к сети (`snapToNetwork`), перекрёстки (`findJunctions`: конец пути на внутренней части другого пути или три и более конца в одной точке).
- `engine/PathRenderer.ts` — полотно, опоры, ферма моста, ограждение, тоннельная оболочка, площадки перекрёстков. Детали отключаются при малом экранном размере.
- В `Engine`: черновик пути (клики), режимы перетаскивания `vertex` (точка пути), `pathclick`, `move` для всего пути; история — как для остальных объектов.
